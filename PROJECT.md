# Fireova Marketing Hub

## Vision

Fireova Marketing Hub is an AI-powered marketing assistant built specifically for Fireova Pizza.

Its purpose is to turn catering events into ready-to-post social media content with almost no manual work.

## Product Principles

- Mobile first
- AI should do the work
- One polished feature at a time
- Premium Apple-quality UI
- Instagram-inspired
- Fireova branding
- Never overwhelm the user
- Every screen answers one question
